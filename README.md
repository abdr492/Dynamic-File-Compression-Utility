# 📦 Dynamic File Compression Utility

A smart and efficient **Dynamic File Compression Utility** built using **Python**, **Huffman Coding**, and advanced **Data Structures & Algorithms** concepts.

This project automatically compresses and decompresses files while optimizing storage usage and improving file transfer efficiency.

It demonstrates core DSA concepts like:

* ✅ Huffman Coding
* ✅ Min Heap / Priority Queue
* ✅ Binary Trees
* ✅ Greedy Algorithms
* ✅ Hash Maps
* ✅ File Handling
* ✅ Compression Algorithms

---

# 📌 Project Overview

File compression is essential in modern systems to reduce:

* Storage usage
* Data transfer time
* Bandwidth consumption
* Backup sizes

This utility intelligently compresses files using **lossless compression techniques**, ensuring that the original file can be perfectly restored during decompression.
